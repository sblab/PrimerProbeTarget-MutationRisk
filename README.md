# PrimerProbeTarget-MutationRisk
Analysis of mutation patterns in binding regions of SARS-CoV-2 primers/probes used in RT-PCR diagnostics. Identifies mutation types, frequencies, and position-specific risks (high and moderate) to assess potential impact of mutation on diagnostic accuracy.
## The repository contains
### 1. **FP_mutation-analysis.ipynb**
- Analyzes mutation patterns in forward primer targets

### 2. **RP_mutation-analysis.ipynb**
- Analyzes mutation patterns in reverse primer targets

### 3. **Probe_mutation-analysis.ipynb**
- Analyzes mutation patterns in probe binding regions

### 4. **Primer_probe_mutation_multiple_Targets.ipynb**
- Performs mutation analysis across multiple primer/probe target regions

### 5. **Primer_probe_mutation_multiple_non-Targets.ipynb**
- Evaluates mutation patterns outside primary target regions
